Eighteen icons, one grid

A–J plus the eight woven C/D colorways are 1024 × 1024 SVGs on an 824 px tile. D’s outlined monogram is reused on the woven labels.

Hero type

The hero SVGs use New York, SF Pro and SF Mono as live text. The 2× PNG previews are the reliable share asset; outline the copy before publishing an SVG to GitHub.

Not wired in

No app code was changed. After you pick, the next step is the Tauri icon set, the in-app mark and the README image.
